# JDS 1.0 — Icon / Emoji 목록

`jobplanet-ds` 스킬의 부속 문서. 아이콘·이모지 **이름을 골라야 할 때만** 이 파일을 읽는다.
이름은 피그마에 있는 그대로이며, 임의로 고치면 찾을 수 없다.

### Graphic — Icon
페이지 `5:7147`. **`system-` 접두사 아이콘 310개** + **`Brand-` 24개**.

- 기본 아트보드 **24×24**. 컴포넌트에 `size` 프로퍼티가 있고 값은 **12 · 14 · 16 · 18 · 20 · 22 · 24 · 28 · 32** 9단계다.
- 파일 안내문: "아이콘은 우측 상단 설정된 사이즈로 선택하여 사용합니다."
- 색은 아이콘 자체에 고정돼 있지 않다. 쓰는 자리의 텍스트 색을 따른다
  (헤더 기준 액션 아이콘 `#686a6d`, 보조 아이콘 `#a4a6ad`).
- **`-line` / `-fill` 페어**가 있는 아이콘은 반드시 짝을 맞춰 쓴다. 기본은 `-line`, 활성·선택 상태가 `-fill`.
